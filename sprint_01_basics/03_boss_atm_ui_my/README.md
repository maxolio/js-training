# 🏧 AETHER Neo-Bank | ATM Terminal Simulator

Интерактивный веб-тренажер терминала банкомата в стилистике **Cyberpunk / Neo-Bank Glassmorphism**.
Проект создан как **Финальный Босс Спринта 1** для практического закрепления базового JavaScript (уроки 02–07).

## 🎯 Что реализовано в проекте

### 🔐 1. Система безопасности и авторизации:
- **PIN-код по умолчанию:** `1234`
- Защита от подбора: лимит в **3 попытки** ввода.
- При 3 неверных вводах карта переходит в статус `🚫 BLOCKED` и клавиатура блокируется.
- Интерактивный ввод через цифровую клавиатуру (Numpad) с визуализацией точек на экране `● ● ● _`.

### 💳 2. Банковские операции:
- **📊 Баланс:** просмотр текущего состояния счета.
- **💸 Снятие наличных ($500):** валидация достаточности средств перед списанием.
- **💳 Пополнение ($1000):** моментальное зачисление средств на баланс.
- **🧾 Печать чека:** генерация детализированной истории всех совершенных транзакций.

## 🧠 Какие концепции JavaScript (ES6+) здесь отработаны:

| Урок / Тема | Где и как применено в коде |
|---|---|
| **02. Переменные и 'use strict'** | `const CORRECT_PIN`, `MAX_ATTEMPTS`, блочный scope `let/const`. |
| **03. Типы данных и интерполяция** | Шаблонные строки `` `... ${USER_NAME}` ``, приведение типов строк к числам. |
| **04. Математика и инкремент** | Арифметика баланса (`+=`, `-=`), инкремент счетчика операций `totalOperations++`, декремент попыток `attemptsLeft--`. |
| **05. Условия и оператор `??`** | Логические связки `&&`, `||`, тернарный оператор для статуса, безопасный дефолт баланса через `??`. |
| **06. Switch Case** | Обработка нажатий меню действий терминала через `switch (actionType)` без избыточных `if/else`. |
| **07. Циклы `for`** | Цикл для отрисовки звездочек ввода PIN и генерации списка транзакций в чеке. |

## 🛠️ Стек технологий
- **HTML5:** семантическая структура терминала и клавиатуры.
- **CSS3:** Flexbox, CSS Grid, Glassmorphism, неоновые тени (`box-shadow`, `text-shadow`), адаптивность под мобильные экраны (Media Queries `@media (max-width: 768px)`).
- **Vanilla JavaScript (ES6+):** работа с DOM, события клика, чистая модульная логика без сторонних библиотек.
