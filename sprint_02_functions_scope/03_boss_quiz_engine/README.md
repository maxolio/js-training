# ⚡ Cyber JS Quiz Engine

Интерактивный квиз-тренажер по продвинутому JavaScript (Замыкания, Call Stack, Hoisting, Scope, TDZ) в неоновом киберпанк-стиле. Написан на чистом **Vanilla JS** без сторонних библиотек.

---

## 🎮 Особенности

- ⏱ **Таймер 15 сек на вопрос** с динамической сменой цвета (красный при $\le 5$ с) и авто-таймаутом.
- 🎯 **Бонусная система очков:** база (100) + бонус за оставшееся время + множитель за серию ответов (Streak).
- 🏆 **Система рангов:** расчет звания от `TRAINEE` до `SENIOR JS ARCHITECT`.
- 🛡 **Защита от дабл-клика:** мгновенная блокировка кнопок после выбора ответа.
- 📱 **Адаптивность:** отлично смотрится как на смартфонах, так и на десктопах.

---

## 🛠 Архитектура и стандарты кода

1. **Движок на замыканиях (`createQuizEngine`):** Полная инкапсуляция приватного состояния (очки, стрик, таймер). Наружу отдается только контролируемый Public API.
2. **Поиск элементов строго по `[data-js-*]`:** Классы стилей полностью отделены от JavaScript-логики.
3. **БЭМ-методология:** Верстка и CSS написаны строго по схеме `block__element--modifier`.
